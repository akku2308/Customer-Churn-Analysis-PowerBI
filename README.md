# Customer Churn Analysis — Power BI

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze customer churn and identify important customer retention patterns.

The dashboard helps understand how customer churn varies across contract type, tenure, age group, payment method status, and gender.

## Business Objective

The main objective of this project is to analyze customer churn and provide actionable insights that can support customer retention strategies and reduce customer loss.

## Key Analysis

- Customer churn rate analysis
- Churn analysis by contract type
- Churn analysis by tenure group
- Churn analysis by age group
- Churn analysis by payment method status
- Churn analysis by gender
- Customer retention insights and recommendations

## Key Insights

- Overall customer churn is approximately 50%.
- Churn remains relatively high across different contract types.
- Churn shows relatively stable patterns across tenure groups.
- Age group and payment method status show smaller variations in churn.
- Customer churn appears to be influenced by multiple factors rather than a single customer attribute.

## Business Impact

This analysis can help businesses:
